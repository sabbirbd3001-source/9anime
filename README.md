# 9Anime CloudStream 3 Plugin Repository 🎬⚡

> **ক্লাউডস্ট্রিম ৩ (CloudStream 3)-এর জন্য [9animes.cam](https://9animes.cam/) এক্সটেনশন রিপোজিটরি।**  
> Complete CloudStream extension repository targeting `https://9animes.cam/` with automated CI/CD builds and video stream extraction.

---

## 📱 ক্লাউডস্ট্রিমে যেভাবে অ্যাড করবেন (How to Add to CloudStream)

1. আপনার ফোনে **CloudStream 3** অ্যাপ খুলুন।
2. **Settings (সেটিংস)** > **Extensions (এক্সটেনশন)**-এ যান।
3. **Add Repository (এড রিপোজিটরি)** বাটনে ট্যাপ করুন।
4. নিচের মতো করে তথ্য দিন:
   - **Repository Name**: `9Anime Repository`
   - **Repository URL**:
     ```text
     https://raw.githubusercontent.com/sabbirbd3001-source/9anime/builds/plugins.json
     ```
5. **Download / Install** বাটনে চাপ দিয়ে `9Anime` প্লাগইন ইনস্টল করে নিন।
